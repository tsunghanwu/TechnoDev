# Task Brief

Use this optional template for a substantial task. Copy it into an issue or your
agent conversation; small changes can be described directly.

## Goal

Describe the script behavior, modeling question, or other outcome you want.

## Acceptance criteria

- State observable behavior and how you will judge success.

## Relevant context

List relevant files, approved inputs, and existing behavior. For modeling work,
include units, parameter meanings, evaluation data, and baseline results where
applicable. Reference sensitive data by location rather than pasting it.

## Constraints

State compatibility requirements, dependency constraints, the selected environment
(local or container), runtime or compute budget, and anything that must be preserved.

## Validation

Specify focused tests, numerical tolerances, or comparison metrics. Identify
experiments or manual checks needed beyond ordinary code checks.
For notebook work, specify approved input data and whether fresh-kernel execution
is feasible. For container changes, include persistence and environment checks.

## Handoff

Ask for a summary of changes, checks actually run and their results, assumptions,
and any remaining limitations.
